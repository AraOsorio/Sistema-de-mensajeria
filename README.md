# 📩 Sistema de Mensajería — Desafío Full Stack

Este proyecto corresponde a un desafío del curso Full Stack Developer de Desafío Latam, cuyo objetivo fue construir la interfaz de un sistema de mensajería utilizando únicamente HTML y CSS, haciendo énfasis en el uso de Flexbox para la organización de los elementos visuales.

🔗 Demo en GitHub Pages:
https://araosorio.github.io/Sistema-de-mensajeria/

## 🎯 Objetivo del Desafío

- Desarrollar el layout de una aplicación de mensajería simulada, aplicando:
- Estructura semántica en HTML.
- Diseño con Flexbox.
- Maquetación basada en componentes visuales.
- Organización visual similar a aplicaciones de mensajería reales.

## 🧩 Estructura del Proyecto

- El sistema simula una aplicación de mensajería compuesta por:
- Panel lateral de contactos
- Área principal de conversación
- Perfil
- Diseño estilo app de mensajería moderna

Todo el layout fue construido usando display: flex, distribuyendo correctamente cada sección para lograr una interfaz limpia y organizada.

## 🛠️ Tecnologías Utilizadas

- HTML5
- CSS3 (Flexbox)
- Git & GitHub Pages para despliegue

## 📐 Conceptos Aplicados
Durante el desarrollo del proyecto se implementaron los siguientes conceptos:

- display: flex
- flex-direction
- justify-content
- align-items
- gap
- Estructuración por secciones
- Jerarquía visual
- Buenas prácticas de maquetación

## 🚀 Aprendizajes

Este desafío permitió reforzar habilidades en:

- Layout con Flexbox
- Distribución de elementos UI
- Orden del código y coherencia visual
